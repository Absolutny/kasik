Веб-приложение для автоматизации работы спортивного комплекса. Система предоставляет удобный интерфейс для клиентов (запись на спортивные услуги), тренерского состава (управление и прием заявок) и администраторов (найм персонала, управление каталогом услуг и аудит безопасности).

---

## 🌟 Основные возможности по ролям

### 👤 Клиент
* **Регистрация и Авторизация**: Создание личного кабинета с соблюдением требований к сложности пароля.
* **Каталог услуг**: Просмотр доступных тренировок, бассейна и залов с описанием и ценами.
* **Онлайн-запись**: Выбор удобной даты и отправка заявки на бронирование.
* **Мои записи**: Отслеживание статусов отправленных заявок (*На рассмотрении*, *Подтверждено*, *Отклонено*).

### 🏋️‍♂️ Тренер
* **Управление заявками**: Панель просмотра поступающих от клиентов запросов на тренировки.
* **Прием / Отклонение**: Подтверждение или отказ в записи в один клик с защитой от случайных нажатий.
* **История заявок**: Наглядное цветовое разделение обработанных и активных записей.

### 🛡️ Администратор
* **Управление каталогом**: Добавление новых спортивных услуг и установка цен.
* **Найм тренеров**: Регистрация новых учетных записей для тренерского состава.
* **Журнал аудита**: Мониторинг действий пользователей, логирование входов, попыток подбора паролей и создания объектов с фиксацией IP-адресов.

---

## 🔒 Безопасность и защищенность

Система разработана с учетом основных рекомендаций **OWASP Top 10**:
* **Хэширование паролей**: Использование `PBKDF2` с алгоритмом `SHA-256` и динамической солью (криптографически стойкое хранение).
* **Защита от Brute-Force**: Ограничение количества попыток входа (Rate Limiting).
* **Защита от XSS и SQL-инъекций**: Экранирование пользовательского ввода и применение параметризованных SQL-запросов (`sqlite3`).
* **Разграничение доступа (RBAC)**: Проверка ролей пользователей через кастомные декораторы (`@login_required`, `@admin_required`, `@trainer_required`).
* **HTTP Security Headers**: Защита заголовками `Content-Security-Policy`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`.

## 🚀 Быстрый запуск

### Вариант 1. Автозапуск (для Windows)

Просто запустите файл **`run.bat`** двойным кликом. Скрипт автоматически проверит базу данных, запустит веб-сервер и откроет сайт в вашем браузере.

---

### Вариант 2. Ручной запуск через консоль

1. **Клонируйте репозиторий:**
```bash
git clone [https://github.com/your-username/sport_complex.git](https://github.com/your-username/sport_complex.git)
cd sport_complex

```


2. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


3. **Инициализируйте базу данных:**
```bash
python init_db.py

```


4. **Запустите приложение:**
```bash
python app.py

```


5. **Откройте в браузере:**
Перейдите по адресу [http://127.0.0.1:5000/](https://www.google.com/search?q=http://127.0.0.1:5000/)
